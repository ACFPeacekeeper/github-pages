# stack/next/

Next.js **configuration** for the documentation website package — the React
counterpart to `stack/nuxt/` on Vue docs sites and to the main repo's
`stack/next/`.

| Path | Role |
| --- | --- |
| `next.config.js` | Canonical Next config (static export, docs-site basePath) |
| `../../next.config.js` | Root re-export |

Primary product remains **Docusaurus** in this package. Use Next scripts only
for multi-framework experiments.
